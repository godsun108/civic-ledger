# Civic Ledger contracts

## Export: evidence_packet.v1
Fields: id, title, summary, jurisdiction, source_urls[], retrieved_at, claims[], limitations[], revision.

Claim shape: id, statement, evidence_refs[], confidence_basis, status (supported / disputed / unresolved / superseded).
Source shape: id, issuing_body, url, publication_date, retrieved_at, access_status, document_hash, excerpt_locator.

Export does not authorize publication. CME independently reviews editorial context and approvals. Corrections generate a new revision, retaining earlier revisions and a change log.
